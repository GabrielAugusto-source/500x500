# Conversor de Imagens 500x500

Ferramenta criada para padronizar e converter imagens para a resolução **500 x 500 pixels**, desenvolvida como parte de um projeto para atender à necessidade de uniformização visual e dimensional de arquivos.

## Contexto do projeto

Durante o desenvolvimento de um projeto, surgiu a necessidade de preparar e padronizar imagens em um formato único (**500 x 500**) de forma prática e repetível, evitando ajustes manuais demorados ou inconsistências de tamanho entre diferentes arquivos.

## O que a aplicação faz

- Padroniza imagens para **500 x 500 pixels**.
- Ajuda a manter consistência visual e dimensional nos arquivos gerados para o fluxo do projeto.
- Permite reutilizar e adaptar o processamento de forma simples.

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/GabrielAugusto-source/conversor-imagens-500x500.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd conversor-imagens-500x500
   ```

3. Siga as instruções do arquivo principal do projeto para executar a conversão.

## Observações

Projeto desenvolvido com foco prático para resolver uma demanda específica de padronização de imagens em contexto de projeto.
